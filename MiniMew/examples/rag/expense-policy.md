# 差旅报销制度

本制度仅适用于员工因公出差期间发生的费用。日常办公不适用本制度。

## 餐费

正式员工出差期间，每人每日餐费报销上限为 150 元。超过上限的部分自行承担。

提交申请时，应附出差审批记录和餐费票据。缺少材料时，财务退回补充材料。

## 住宿费

住宿报销上限由出差目的地类别决定，申请时应附酒店发票。

| 目的地类别 | 每晚报销上限 |
| --- | --- |
| 一类城市 | 500 元 |
| 其他城市 | 350 元 |

## 操作示例

下面是配置示例，代码里的井号不是文档标题：

```ini
# 餐费预算
meal_limit = 150
```

## 例外

试用期员工须在出差前完成额外审批。紧急出差应在返回后补交审批材料。
